# Implementasi Early Stopping untuk ACOS-IndoBERT Training

## Ringkasan
Menambahkan early stopping ke **Step 1 dan Step 2** agar training berhenti otomatis jika F1 tidak membaik selama **5 epoch berturut-turut** (patience), dengan syarat training sudah berjalan minimal **5 epoch** terlebih dahulu.

## Parameter Early Stopping
```python
PATIENCE = 5                    # Berhenti jika F1 tidak membaik selama N epoch
MIN_EPOCHS_BEFORE_STOP = 5     # Minimal 5 epoch sebelum early stopping aktif
```

## Mekanisme Kerja
1. Setiap epoch, cek apakah `val_f1 > best_step1_f1`
2. Jika ya: reset `epochs_since_best_1 = 0`
3. Jika tidak: increment `epochs_since_best_1 += 1`
4. Setelah rolling checkpoint, cek: `epoch >= MIN_EPOCHS_BEFORE_STOP and epochs_since_best_1 >= PATIENCE`
5. Jika kondisi terpenuhi: log pesan early stopping, set flag, `break` dari loop
6. Setelah break: hapus rolling checkpoint final, update resume JSON, print pesan final

## Tindakan: Simpan Dev Plan sebagai Markdown (tanpa mengimplementasi notebook)

Pengguna meminta agar rencana notebook IndoBERT **disimpan dulu sebagai dokumen dev plan markdown**, sebelum implementasi.

### Yang akan saya lakukan
Menulis satu file dokumen:
- `docs/devplan_indobert_notebook_modular_pluggable.md`

Berisi rencana lengkap (murni dokumentasi, tidak ada kode eksekusi):
1. Tujuan & keputusan pengguna (Full pipeline + gates / adapter runtime + patch opsional / LANG=en & id).
2. Prinsip desain: modular, pluggable, dinamis, aman untuk upstream.
3. Tiga registry pluggable: `MODEL_REGISTRY`, `DOMAIN_REGISTRY`, `DATA_REGISTRY`.
4. Deliverable D1–D5 dari PRD yang diwujudkan dalam notebook.
5. Rancangan runtime adapter (monkey-patch) menggantikan bloker hardcode `768`, logging `missing_keys` tertutup, dan fallback `[UNK]`.
6. Tiga gate verifikasi (bobot termuat / regenerasi tokenized_data / end-to-end).
7. Alur cell notebook (roadmap).
8. Hyperparameter awal, metrik, lingkungan, validasi, dan catatan risiko.

Catatan: Saya tidak akan membuat/implementasi notebook sekarang — hanya menyimpan dokumen rencana. Setelah file tersimpan, proses berhenti (tidak lanjut ke implementasi notebook tanpa instruksi lanjut).

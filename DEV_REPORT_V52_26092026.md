## 🔍 Problem Analysis: V5.1 Issues

### **Primary Issue: bert_utils ModuleNotFoundError**

**Symptom:**
```python
Cell 3 execution:
ModuleNotFoundError: No module named 'bert_utils'
```

**Root Cause Analysis:**

1. **Conflicting Path Setup Logic**
   - Cell 3 memiliki DUA blok setup path yang bertentangan
   - Blok pertama: Setup kompleks → import prematur (GAGAL)
   - Blok kedua: V4/V4.1 style `ensure_path()` → import delayed (SUKSES tapi terlambat)

2. **Timing Issue**
   ```python
   # Line ~680: Print "Importing modules..."
   # Line ~236: Import bert_utils (PREMATURE - path belum ready!)
   # Line ~705: ensure_path() called (TOO LATE!)
   ```

3. **sys.path Ordering Problem**
   - Path tidak diatur dengan urutan yang benar
   - `bert_utils/` tidak accessible saat import pertama

**Impact:**
- ❌ 100% failure rate di semua percobaan Cell 3
- ❌ Blocking untuk semua eksperimen
- ❌ Manual workaround tidak reliable

### **Secondary Issue: Empty Results**

**Symptom:**
```
Indeks Artefak Laporan: All folders show 0 files
```

**Root Cause:**
- `DRY_RUN = True` by default (preview mode, no actual training)
- User tidak aware training belum berjalan
- Tidak ada diagnostic tools untuk detect ini

## 🔬 Technical Implementation Details

### **Environment Detection Algorithm**

```python
def detect_environment():
    # Priority-based detection
    1. Check google.colab module (Colab-specific)
       └── Import success → COLAB detected
    
    2. Check /kaggle folder existence
       └── Exists → KAGGLE detected
    
    3. Check IPython.get_ipython()
       └── Available → JUPYTER detected
    
    4. Check hostname patterns
       ├── 'aws'/'ec2' → AWS detected
       ├── 'gcp'/'google' → GCP detected
       ├── 'azure' → AZURE detected
       └── 'droplet'/'vultr' → VPS detected
    
    5. Fallback → LOCAL detected
```

### **Path Setup Algorithm**

```python
def setup_paths_v52():
    # Get project paths from ENV_CONFIG
    candidates = env_config['project_paths']
    
    # Find existing project
    for candidate in candidates:
        extract_path = candidate / "Extract-Classify-ACOS"
        if validate_upstream(extract_path):
            upstream_root = extract_path
            break
    
    # Clone if not found (cloud only)
    if not upstream_root and is_cloud:
        clone_acos_project()
    
    # Setup sys.path in CORRECT order
    sys.path.insert(0, upstream_root)    # 1st: bert_utils here
    sys.path.insert(0, indo_root)        # 2nd: acos_id here
    sys.path.insert(0, base_project)     # 3rd: base
    
    # Now safe to import
    from bert_utils.tokenization import BertTokenizer  ✅
```

### **GPU Tier Classification**

```python
def classify_gpu_tier(gpu_name, vram_gb):
    if 'T4' in gpu_name or vram_gb <= 20:
        return 'SMALL'   # batch 16/8, accum 4
    elif 'L4' in gpu_name or vram_gb <= 40:
        return 'MEDIUM'  # batch 32/24, accum 2
    else:  # V100, A100, MI300X
        return 'LARGE'   # batch 96/64, accum 1
```

## 🎓 Key Learnings

### **Technical Insights**

1. **Path Setup is Critical**
   - Order matters: upstream → indo → base
   - Must prepend (not append) to sys.path
   - Validate before import

2. **Platform Detection is Reliable**
   - Module imports work (google.colab)
   - Filesystem checks work (/kaggle)
   - Hostname patterns work (AWS/GCP)

3. **User Experience Matters**
   - Clear error messages reduce support burden
   - Diagnostic tools accelerate troubleshooting
   - Auto-configuration prevents user errors

### **Design Patterns**

1. **Progressive Enhancement**
   ```
   Basic detection → Enhanced validation → Fallback options
   ```

2. **Fail-Fast with Clear Messages**
   ```python
   if not valid:
       print("❌ PROBLEM: X is wrong")
       print("💡 SOLUTION: Do Y")
       raise Error("Clear message")
   ```

3. **Configuration as Code**
   ```python
   ENV_CONFIG = detect_environment()
   # All subsequent cells use this
   ```

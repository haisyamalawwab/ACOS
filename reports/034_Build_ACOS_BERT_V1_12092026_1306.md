## 3. Perbaikan bug baseline lama

- **KeyError `a--1,-1`** (rep. 004/030): bridge meniru `get_1st_pairs.py` (kupas
  prefix, tulis `-1,-1`) + assertion menolak token `a-` mencapai tokenizer.
  `convert_examples_to_features[2nd]` menangani `-1` secara native (flag
  implisit), jadi crash hanya mungkin dari parsing notebook — kini tertutup.
- **Upstream read-only**: Step-2 memakai work-dir sesi
  (`results/<sesi>/tokenized_data/` = salinan + 1st hasil sendiri); processor
  menerima `data_dir` apa pun sehingga tidak perlu patch path.
- **Resume L3 + early stopping** (PATIENCE=5, MIN=5): `*_resume.json` +
  rolling `stepN_epoch_*` (bobot + optimizer + global_step, `t_total` penuh).
- **Lingkungan**: deteksi Colab (Drive opsional `USE_DRIVE`) / JupyterLab /
  lokal via marker `Extract-Classify-ACOS/` + `ACOS-BERT/`; tanpa argumen path.

# ACOS-BERT

Pipeline ACOS dua tahap (Step-1 co-extraction aspek-opini, Step-2 klasifikasi
kategori-sentimen single-head) untuk **dataset Inggris bawaan repo**
(rest16 + laptop), dengan backbone **bert-base-uncased yang di-fine-tune
di sini**.

Folder ini berdiri sendiri. Repo `Extract-Classify-ACOS/` di folder induk
dipakai **hanya untuk dibaca** — tidak satu berkas pun di sana diubah, dan
tidak satu artefak run pun ditulis ke sana. (Step-2 memakai work-dir sesi
`results/<sesi>/tokenized_data/` berisi salinan + `*_test_pair_1st.tsv`
hasil bridge sendiri.)

```
ACOS-BERT/
  acos_en/          paket lapisan Inggris (7 modul, torch-free kecuali checkpoint.py)
  backbones/        bert_base_uncased/ (vocab; tanpa rekey — prefix bert.* asli)
  notebooks/        _build_v1_bert.py + 00_ACOS_Master_Pipeline_V1_BERT.ipynb + V1_01..04
  results/          folder sesi <domain>_<timestamp>/ (checkpoints, csv, md, plots, logs)
  build/            keluaran sementara
  data/             (dokumentasi saja — data dibaca dari repo induk)
```

## Cara pakai

**Colab / JupyterLab / lokal** — buka `notebooks/00_ACOS_Master_Pipeline_V1_BERT.ipynb`,
jalankan berurutan. Sel 1 (env) dan 2 (konfigurasi) wajib diulang setiap
restart kernel. Sel 4 (gate) dan Gate-1 di sel training — kalau merah,
berhenti di situ. Deteksi lingkungan otomatis: Colab (Drive opsional via
`USE_DRIVE`), JupyterLab, atau lokal — tanpa argumen path.

**Lokal** — tanpa torch pun verifikasi berikut jalan:

```bash
python -m acos_en.selftest --domain rest16   # 3 gate torch-free
python -m acos_en.selftest --domain laptop   # 3 gate torch-free
python notebooks/_build_v1_bert.py           # bangun ulang notebook (deterministik)
python notebooks/_split_v1.py                # pecah menjadi V1_01..04 serial
```

`python -c "from acos_en.checkpoint import verify_weights"` + sel Gate-1
menyiapkan verifikasi bobot, tetapi butuh torch — jalankan di Colab/JupyterLab
dengan GPU.

## Perbaikan vs. baseline lama

- **KeyError `a--1,-1`**: bridge meniru `get_1st_pairs.py` (kupas prefix,
  tulis `-1,-1`) + assertion menolak token `a-` lolos ke tokenizer.
- **Resume level-3 + early stopping** (PATIENCE=5): sesi putus lanjut dari
  epoch terakhir, bukan dari nol.
- **Gate-1**: verifikasi bobot encoder (numerik bila `pytorch_model.bin`
  lokal ada; struktural bila unduhan runtime).
- **15 subtask post-hoc** via `SubtaskMetricCapture` + `master_metrics.json`.
